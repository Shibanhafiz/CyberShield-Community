# VTU Evidence Checklist — Field Study (template)

> Tick only what physically exists in `evidence/` (or cited appendix).
> Fabricated ticks are academic misconduct — when in doubt, leave blank.

- [ ] Problem identification record (dated)
- [ ] Stakeholder interaction log entries (dated, anonymized)
- [ ] Baseline survey tallies (dated)
- [ ] Pre-assessment records (app sessions and/or paper)
- [ ] Awareness session records (dates, headcounts, observations)
- [ ] Post-assessment records
- [ ] Feedback tallies (paper + in-app export, dated)
- [ ] Impact measurement sheet (numbers trace to dated sources)
- [ ] Photographic evidence (venue/activity only — no faces, no personal data)
- [ ] Field notes (dated)
- [ ] Dated API snapshots (`/api/impact/summary`, `/api/community/stats`) supporting every quoted number
- [ ] Final report section drafted from the above (no invented numbers)
- [ ] Presentation prepared from the report (same numbers)
- [ ] Viva Q&A rehearsed (`docs/viva-questions.md`)

Storage: raw material under `evidence/<area>/` (raw formats are
git-ignored by `evidence/.gitignore` — keep originals with the team and
commit only redacted summaries).
