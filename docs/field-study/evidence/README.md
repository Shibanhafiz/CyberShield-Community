# Field-study evidence store (team-local)

This folder holds REAL evidence collected during field implementation.
Nothing here is generated by the application team in advance — every file
added must come from an actual dated interaction.

## Layout

```text
evidence/
├── stakeholder-interaction/  completed stakeholder-interview.md copies
├── survey/                   completed awareness-survey.md tallies
├── awareness-activity/       pre/post-assessment.md + session notes
├── feedback/                 feedback exports (CSV) with collection dates
├── photos/                   event photos ONLY with visible consent
└── reports/                  dated community/API snapshots
```

## Rules

- No names, phone numbers, addresses, or other identifying details in any
  file. Use participant categories and broad localities only.
- Raw material that could identify someone must NOT be committed — keep it
  with the faculty coordinator. A `.gitignore` in this folder excludes
  common raw formats; only cleaned, anonymized summaries are committed.
- Every number in `impact-measurement.md` must trace to a file here.
