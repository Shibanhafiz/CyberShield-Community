# Field-Study Package

How the team runs the actual community activity with CyberShield.
**Every file here is a blank template or a guide — fill only with real,
dated field data. Never fabricate participants, quotes, or numbers.**

## Package index

| File | Purpose |
|---|---|
| `problem-identification.md` | Record the observed problem (template) |
| `stakeholder-interaction.md` | Log each stakeholder interaction: date, category, locality, problem, challenges, requirements, suggestions, action, follow-up (template) |
| `stakeholder-interview.md` | Guiding questions for interviews (existing) |
| `survey-form.md` | Baseline community survey instrument (template) |
| `awareness-survey.md` | Short in-session awareness tally (existing) |
| `pre-assessment.md` / `post-assessment.md` | Before/after instruments (existing; mirror the in-app 6-question assessment) |
| `awareness-session.md` | Session plan + attendance/observation sheet (template) |
| `feedback-form.md` | Participant feedback collection (template; mirrors in-app feedback) |
| `impact-analysis.md` | Honest-reporting guide: allowed vs forbidden claims (existing) |
| `impact-measurement.md` | Summary sheet — numbers only from dated sources (existing) |
| `data-collection-procedure.md` | How to collect data responsibly (existing) |
| `admin-guide.md` | How reviewers use the admin console during the study (existing) |
| `evidence-checklist.md` | What evidence to retain for VTU (template) |
| `evidence/` | Dated raw material only (photos, tallies, snapshots; raw formats git-ignored) |

## Honesty rules (non-negotiable)

1. No names, phone numbers, addresses, or signatures in any file.
2. Every number traces to a dated source (form, tally, or API snapshot).
3. Distinguish **system usage** vs **awareness change** vs **real-world
   scam reduction** — the study can only directly measure the first two.
4. Demo/seed rows (`is_demo_data=True`, `[DEVELOPMENT SAMPLE DATA]`) must
   never appear in field counts — the app excludes them by default; verify
   before quoting any number.
