# Screenshot Checklist (capture from the real app — no mockups)

Run the stack (`docker compose up` or dev servers), use clearly fictional
demo content (e.g. "DEMO BANK", Demo Town), and capture:

1. Landing page (hero + how-it-works)
2. Message analyzer (input + tabs)
3. Analysis result (risk badge, indicators, recommendation)
4. URL analyzer (technical details + reputation-unavailable note)
5. Community dashboard (stats + charts + area table, or honest empty state)
6. Learn page (topics + scenarios)
7. Scenario (message + choices + explanation)
8. Quiz (progress + score + recommendations)
9. Awareness result (before → after difference wording)
10. Admin dashboard (overview cards)
11. Report moderation (list + detail with duplicates)
12. Analytics (trends/categories)

Rules: real captures only; fictional demo content only; never participant
data, real messages, or real credentials. Store originals with the report;
do not commit large binaries casually (consider `docs/assets/` + Git LFS
if the team prefers them versioned).
