# Objectives

**Status: implemented and tested (each maps to shipped functionality).**

1. Let anyone check a suspicious message/URL and **understand why** it was flagged (explainable indicators + safe action).
2. Never visit, fetch or execute submitted links (static URL analysis only).
3. Collect **anonymous** community reports with duplicate detection and redaction-before-storage.
4. Teach scam patterns (topics, scenarios) and measure learning honestly (quiz + before/after difference).
5. Give reviewers an audited moderation + analytics console with role separation.
6. Prove nothing with fake numbers: honest empty states, demo-data separation, evidence-backed impact only.

Non-objectives: guaranteed detection, verdicts of guilt, real-world immunity measurement, contacting authorities automatically.
