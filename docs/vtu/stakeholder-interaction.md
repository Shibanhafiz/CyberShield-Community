## Protocol for the team

1. Identify a stakeholder type first (teacher, merchant, homemaker, senior
   citizen, student, local official, other) and the community context
   (school, market area, residential group — general locality only).
2. Explain the purpose (VTU community project on scam awareness), that
   participation is voluntary and anonymous, and that no personal details
   are recorded.
3. Ask the guiding questions (`stakeholder-interview.md`): scam types
   seen locally, usual reactions, confusions, existing awareness practices,
   what would help, whether a free checking tool would be used.
4. Record the same day in the table below (codes like S-01, never names).
