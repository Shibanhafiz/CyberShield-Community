# Field Study Ethics (practical guidance, not a legal document)

- **Voluntary participation**: explain the purpose in plain language;
  anyone may skip any question or leave at any time, no consequences.
- **Anonymous by design**: session codes and headcounts only — no names,
  phone numbers, Aadhaar, addresses, faces in photos, or signatures.
- **No sensitive content**: forbid real passwords, OTPs, PINs, bank/card
  details and private conversations in the tool and on paper; use the
  synthetic examples from the demo procedure.
- **Purpose limitation**: data is used only for this VTU project
  evaluation (awareness measurement + usability), never shared externally.
- **Photos**: venue/activity only, and only where venue/community
  permission allows; when in doubt, take none.
- **Vulnerable groups**: extra care with seniors/students — slower pace,
  local language, a helper present; stop if anyone is distressed (scam
  victims may be reliving loss — offer helpline 1930 information).
- **Children**: avoid collecting data from minors without guardian consent
  and institutional permission; prefer adult community groups.

> No formal ethical approval is claimed. If the institution requires an
> ethics clearance for community studies, obtain it before Phase 9 field
> sessions and file the approval with the evidence.
