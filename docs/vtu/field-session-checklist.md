# Field Session Checklist (per session)

## Before

- [ ] Venue + permission confirmed, recorded
- [ ] Device(s) charged; app reachable (or offline fallback: paper forms)
- [ ] Printed: survey sheets, feedback forms, attendance headcount sheet
- [ ] Roles assigned (facilitator / observer / data steward)
- [ ] Consent script ready (anonymous, voluntary, may leave anytime, no photos of faces)

## During

- [ ] Headcount recorded (no names)
- [ ] Baseline survey administered
- [ ] Before-assessment completed (app session IDs noted, anonymous)
- [ ] Topics + scenarios delivered
- [ ] After-assessment + feedback collected
- [ ] Usability issues noted verbatim (anonymized)
- [ ] Venue/activity photos taken (no faces, no personal data)

## After

- [ ] Tallies transcribed same day; raw sheets stored with team
- [ ] Dated summary filed under `docs/field-study/evidence/`
- [ ] `awareness-session.md` record completed
- [ ] Issues fed back to the build notes (no code change without a test)
