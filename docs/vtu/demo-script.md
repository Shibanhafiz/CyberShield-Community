# Demo Script (5–7 minutes, fictional data only)

> Use clearly fictional content (e.g. “DEMO BANK”, Demo Town). Never real
> messages, real credentials, or participant data.

1. **Problem (30s):** “People act before they verify. CyberShield gives a
   second opinion — *check before you trust*.”
2. **Why awareness alone isn’t enough (30s):** advice is ignored in the
   moment; a tool at the moment of doubt helps.
3. **Message analysis (60s):** paste the fictional KYC-suspension SMS →
   HIGH/BANKING_SCAM → point at 2–3 indicators.
4. **URL analysis (45s):** `http://paypa1-example.com/login` → typosquat +
   path signals; stress: *never visited*.
5. **Explainable result (30s):** category, why-flagged, recommended
   action, limitation note — score is secondary.
6. **Community reporting (30s):** submit → duplicate-strengthening message
   on repeat → dashboard count moves (or honest empty state).
7. **Community dashboard (30s):** real aggregates only; demo rows excluded.
8. **Awareness/quiz (45s):** scenario choice → quiz → before/after
   difference wording (“changed by…”, never “protected”).
9. **Admin moderation (60s):** login → filter → open → REVIEWED → audit
   entry appears → export CSV (formula-safe).
10. **Societal impact (30s):** what’s measured vs what isn’t — usage,
    awareness change, and (future) real-world reduction, kept separate.
11. **Field validation (30s):** instruments ready; evidence comes next.

Backup lines if offline: narrate from `docs/screenshots.md` captures.
