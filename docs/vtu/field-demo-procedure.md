# Field Demonstration Procedure (facilitator script)

**Status: procedure ready; no session delivered yet.**

Use synthetic examples only (fictional bank names, Demo Town). State
up front: *“CyberShield gives a risk assessment to help you decide — it
cannot guarantee scam detection. Never type real passwords, OTPs, or bank
details here.”* The app repeats this warning on the analyzer screen.

1. **Explain the problem** (2 min): scam messages pressure quick action;
   checking first beats regretting later.
2. **Realistic suspicious message** (fictional KYC-suspension SMS): read it
   aloud; ask the group what feels wrong before touching the tool.
3. **Submit to CyberShield** (`/analyze`): show the HIGH/banking result.
4. **Detected indicators**: point at 2–3 (urgency, account threat,
   credential request) in plain words.
5. **Recommended safe action**: verify via the official app/helpline —
   never the message itself.
6. **Suspicious URL** (`/analyze/url`, e.g. a typosquat login link):
   show structural signals; stress the link was **never visited**.
7. **Not absolute proof**: indicators support caution; a clean-looking
   message can still be fraud and vice versa.
8. **Reporting** (`/report`): redacted, anonymous, duplicates strengthen
   the signal; show the community count move (or the honest empty state).
9. **Awareness/quiz**: one scenario together, then hand over for the
   hands-on activity (synthetic examples; no real private conversations).

Timebox: ~15 minutes, then participants practice.
